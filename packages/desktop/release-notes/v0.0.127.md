# Release Notes v0.0.127

- The `draft / sending / queued` states showed a phantom solid core: the background-colored punch circle lived in the crisp overlay, whose opacity let 20% of the goo bump bleed through. Punches now live in their own full-opacity layer between the goo and the buttons.
- Added a reply feature in the prompt widget. Replied text is prepended to the prompt and its address range is available to the agent as extra context.
- Added a document read range tool to allow the agents read the context of the replied-to-text.
